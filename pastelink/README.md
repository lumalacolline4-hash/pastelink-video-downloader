# Pastelink - Video Downloader

Pastelink is a high-performance web application designed for downloading HD video and pristine audio directly to device storage from YouTube, TikTok, Instagram, Twitter/X, Reddit, Facebook, Vimeo, and direct web video streams.

## Features
- **Auto-Detection:** Automatically identifies platforms (TikTok, Instagram, Facebook, YouTube, etc.) as soon as you paste a link.
- **Multiple Quality Formats:** HD (1080p), SD (720p), and Audio Only (MP3 320kbps).
- **Fast Media Processing:** Built with `yt-dlp` and `ffmpeg` for robust multiplexing and rapid transcoding.
- **Clean SaaS UI:** Dark/Light theme toggle, floating platform indicators, smooth animations, and no intrusive ads.
- **SSRF & Command Injection Protection:** Enterprise security guards against private subnets and shell injections.

## Project Structure
- `index.html`: Modern semantic HTML interface
- `style.css`: Responsive stylesheet with dark SaaS neon aesthetic
- `script.js`: Interactive client logic with clipboard paste and format selector
- `assets/`: Media and icon assets
